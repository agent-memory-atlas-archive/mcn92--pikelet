Ask it something

The badge on each answer is match quality, not a fact-check: it measures how well the retrieved passage matches your question, not whether that passage actually contains the specific claim you asked about. At Wikipedia's scale almost every question has some topically related article, so strong mostly means "an article about this exists" — it can be confidently wrong on a specific detail the article doesn't cover. The one place this file reliably withholds is when the topic itself is missing, which is what the fact-removal tab shows.
